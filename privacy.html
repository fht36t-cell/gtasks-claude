Privacy Policy

Last updated: 2026-11-07

  • gtasks-claude is used only by its developer, for the developer's own Google account.
  • It requests the Google Tasks scope (https://www.googleapis.com/auth/tasks) only to list, create, update, complete and delete the developer's own tasks.
  • Task data is processed only on the developer's own PC. It is not sent to any server operated by this tool, not sold, and not shared with third parties.
  • OAuth tokens are stored only in a local file on the developer's PC. Access can be revoked at any time from Google Account permissions.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

プライバシーポリシー（日本語）

  • gtasks-claude は開発者本人だけが、本人の Google アカウントに対して使います。
  • Google Tasks の権限は、本人のタスクの一覧・作成・変更・完了・削除のためだけに使います。
  • タスクのデータは本人の PC 上でだけ処理し、このツールのサーバーへの送信・販売・第三者への提供はしません。
  • OAuth のトークンは本人の PC のファイルにだけ保存します。Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
